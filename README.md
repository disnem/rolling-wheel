# Rolling Wheel

Обновлённый сайт шиномонтажных мастерских Rolling Wheel в Екатеринбурге. Статические страницы работают на GitHub Pages без сборки.

- `index.html` — главная с услугами, адресами и телефонами.
- `services/` — страницы 17 услуг.
- `prices.html` и `assets/prices/` — таблицы и оригинальные документы за весну 2025 года.
- `about.html`, `news.html`, `sitemap.html` — история, архив новостей и структура сайта.

Источник информации — действующие страницы [rwheel.ru](http://rwheel.ru/). Ссылка «Обратная связь» ведёт к исходной форме мастерской. Фотография на главном экране создана для концепта. Портрет владельца и фотографии работ взяты с оригинального сайта.
